# Teacher Module User Guide

The **Teacher Module** in Parakh Portal is designed to provide comprehensive tools for academic management, assessment creation, and performance analysis. This guide will walk you through its key features.

## 1. Getting Started

### Registration & Login
1.  Navigate to the **Login** page (`/login`).
2.  Log in using your **Teacher credentials**.
3.  Upon successful login, you will be redirected to the **Teacher Dashboard**.
    *   *Note: If you are registering a new account, ensure you select 'Teacher' as your role. New accounts may require Admin approval before login.*

## 2. Dashboard Overview (`Overview` Tab)
The **Overview** tab serves as your command center, displaying key academic metrics at a glance:
*   **Quick Stats**: Total Classes, Students, Questions, Tests, Active Tests, and Average Class Score.
*   **Performance Trends**: Visual charts showing recent performance data.
*   **Quick Actions**: Shortcuts to create assessments, add questions, or manage classes.
*   **Recent Activity**: A logs feed of your recent actions (e.g., Created Assessment, Added Student).

## 3. Managing Classes (`My Classes` Tab)
This section allows you to organize your students into classrooms.
*   **Create a Class**: Click the **"+ New Class"** button.
    *   Enter the **Class Name** (e.g., "Grade 10 - Section A") and **Subject**.
    *   Add a description if needed.
*   **Manage Students**:
    *   Click on a class card to view details.
    *   **Add Student**: Enter a student's email to enroll them in the class.
    *   **Remove Student**: Click the **Trash icon** next to a student's name to remove them.
*   **Class Analytics**: From the class details, you can quickly jump to view specific performance reports.

## 4. Building Your Question Bank (`Question Bank` Tab)
The Question Bank is your central repository for assessment content.
*   **Add Questions**: Click **"+ Add Question"**.
    *   Fill in the **Question Text**, **Options (A, B, C, D)**, **Correct Option**, **Subject**, **Topic**, and **Difficulty level**.
*   **Bulk Management**:
    *   Use the checkboxes to select multiple questions.
    *   Click the **"Delete Selected"** button to remove them in bulk.
*   **Filtering**: Use the Subject and Difficulty filters to find specific questions quickly.

## 5. Creating Assessments (`Assessments` Tab)
Create and manage tests for your classes.
*   **Create New Assessment**: Click **"+ New Assessment"**. This opens the **Test Builder Wizard**:
    1.  **Basic Info**: Title, Target Class, Duration.
    2.  **Select Mode**:
        *   **Auto-Generate**: System randomly picks questions based on Topic and Difficulty.
        *   **Question Bank**: Manually select questions from your bank.
        *   **Upload PDF**: Upload an existing question paper (students view PDF and submit answers).
    3.  **Configure**: Set question count (Auto), select specific questions (Manual), or upload file (PDF).
    4.  **Review & Publish**: Confirm details and publish.
*   **Manage Assessments**:
    *   View list of all assessments with their status (Active, Completed).
    *   **Delete**: Remove assessments using the Delete button (only if no student attempts exist).

## 6. Performance Analytics (`Student Performance` Tab)
Gain insights into student learning outcomes.
*   **Class Selection**: Use the dropdown to select a specific class.
*   **Visual Reports**:
    *   **Assessment History**: Trend line of class average scores over time.
    *   **Topic Strength**: Radar chart showing proficiency in different topics.
    *   **Difficulty Success Rate**: Bar chart comparing performance across Easy, Medium, and Hard questions.
*   **Student Results Table**: Detailed table showing individual student scores, completion status, and exam dates.

---
**Tips for Success:**
*   Regularly update your Question Bank to keep assessments fresh.
*   Use the "Difficulty" setting in questions to create balanced tests for different student levels.
*   Monitor "Recent Activity" on the dashboard to keep track of changes.
